# Build plan (validation first)

Nothing below starts without the owner's approval.

## Phase 0, days 1-14: no code
- F1 landscape scan. F2: ~10 conversations with small brokers/3PLs (owner approves and sends every message). Record the exceptions that hurt most, current tools, and willingness to pay for a pilot.
- Decision: go, change the segment, or stop.

## Phase 1, days 14-35: smallest tool
- CSV import, three rules (the ones brokers named), case list UI, drafted follow-ups. Synthetic data only for tests; a pilot customer's data only with their written permission.
- Measure on pilot data: exceptions caught, false alarms, minutes saved (self-reported).

## Phase 2, only after a pilot says yes
- Read-only email ingestion (after F4), more rules, auth, billing.

## Gate
Ten conversations done before any code; one paid pilot within 60 days (estimates). Kill: nobody names a repeated, costly exception they would pay to reduce.
